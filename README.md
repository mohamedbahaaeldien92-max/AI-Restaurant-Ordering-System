# 🍔 AI-Powered Restaurant Ordering & Analytics System

An end-to-end AI automation project built using:

* OpenAI GPT-4o-mini
* n8n Workflow Automation
* Telegram Bot API
* Google Sheets
* Microsoft Power BI

## 🚀 Project Overview

This project is an AI-powered restaurant ordering and analytics system that automates customer ordering workflows using conversational AI and real-time business intelligence.

Customers can:

* Place orders through Telegram
* Chat with an AI assistant in Egyptian Arabic
* Receive automated order confirmations
* Get delivery and discount calculations instantly

The system automatically:

* Extracts structured order data
* Stores orders in Google Sheets
* Pushes data to Power BI
* Updates dashboards in real time
